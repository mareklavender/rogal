Plain

A small language that is genuinely easy to write. Twenty-nine words, one way to write each thing, and a mistake tells you what to do about it instead of what went wrong inside the machine.

The whole language

Not a summary — 29 words and 24 built-in actions is everything Plain has. Nothing to install, nothing to import.

Instructions

set x to 5Create a name. Fails if it already exists.
change x to 9Give an existing name a new value. Fails if it doesn't exist.
show xDisplay something. Commas show several on one line.
if … endWith optional else and else if.
for each n in xsGo through a list or the letters of text.
repeat 5 timesDo something a fixed number of times.
while testKeep going until the test is false.
stopLeave the loop early.
make name(a)Create an action. give hands a value back.

Comparing

isExactly the same. There is no ==.
is notDifferent.
is more thanBigger.
is less thanSmaller.
is at leastBigger or the same.
is at mostSmaller or the same.
and or notCombine tests.

Kinds of value

12 3.5Numbers. + - * / and % for remainder.
"hello"Text. + joins it, numbers included.
true falseThe only things an if accepts.
[1, 2, 3]A list. Items count from 1, so xs[1] is the first.
{name: "Ada"}A record. Read fields with person.name.
nothingNo value yet.
# noteA note to yourself, ignored when running.

Built in, always available

count hasHow many; whether something is in there.
add removeA new list with one item added or taken out. For two lists use a + b.
first last reverseReach into a list, or turn it round.
sumAdd up a list of numbers.
sort_up sort_downIn order. Add a field name to sort records: sort_up(people, "born")
join splitText to list and back.
upper lower trimTidy up text.
round randomNumbers. round(x, 2) for decimal places.
text number keysConvert between kinds; list a record's fields.

Five decisions do most of the work: blocks end with end, so indentation can never break a program; comparisons are words, so = and == can't be confused; set creates and change alters, so a typo can never quietly make a second variable; a name holds a value, never a link to someone else's, so nothing changes at a distance; and lists count from 1, matching how people already count.
